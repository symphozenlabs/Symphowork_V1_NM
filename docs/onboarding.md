# Onboarding

Employee onboarding has explicit records and statuses: `not_started`, `invited`, `in_progress`, `completed`, and `blocked`. Checklist items are stored separately so future workflows can add configurable steps.

Creating an employee does not make the person active automatically. Invitation acceptance links a user to the existing employee and moves the employee to onboarding. Completion requires no pending checklist items and then transitions the employee to active.
