# Technical compliance foundation

SymphoWork has a technical foundation for tenant isolation, RBAC, audit logging, data minimization, candidate consent/retention metadata, signed private-file access, soft deletion in collaboration, and controlled exports.

This does not constitute GDPR, SOC 2, ISO, or any other formal certification. Production owners must define retention schedules, deletion/export workflows, incident response, access reviews, backups, data-processing agreements, regional hosting requirements, and legal policies before making compliance claims.
